How & Why I Built This Site

This portfolio is a project in its own right. I created it as a practical way to learn and experiment with version control, automated deployment, hosting and cloud infrastructure, rather than just write about those technologies on a CV.

The Deployment Workflow

  • GitHub: Stores the source code and tracks changes. I can work on a separate branch and review changes before updating the live site.
  • Cloudflare Pages: Builds and deploys the website from GitHub, including preview deployments for branches so I can test updates before publishing.
  • Cloudflare DNS & HTTPS: Serves the site on my own domain with secure connections and Cloudflare's edge network.
  • Continuous learning: I use this project to explore HTML, CSS, JavaScript and CI/CD concepts, and improve the site as I learn more.

It's deliberately a working portfolio rather than a finished showcase — I like having somewhere I can try things, break them, fix them and keep learning.
