BaizeBoard

React Vite Supabase Stripe Cloudflare Pages Progressive Web App

A full-stack snooker scoring platform built for clubs and casual players alike. BaizeBoard handles real-time frame scoring, break tracking, foul penalties, and full match statistics — all from the table edge on any device.

What started as a personal tool to improve my own match nights evolved into a platform with club management, user authentication, tiered Pro subscriptions via Stripe, and an offline-capable PWA for remote venues. Clubs can register, manage members, and run scored matches with persistent history stored in a Postgres database via Supabase.

Core Architecture Highlights: React SPA with Supabase auth and row-level security, real-time state management for scoring logic, Stripe billing for Pro tier access, and Cloudflare Pages for edge deployment with zero cold starts.
